# Экономика среза

Старт: +5000 ₽ (welcome), диван: −2500 ₽. Остатки — целые игровые рубли, вывода нет. Цена определена на сервере в packages/shared/game.mjs. Клиентские price/user/wallet не влияют на списание.

Ledger проверяемый, не double-entry: каждая операция содержит delta и balance, начальный баланс 0. Welcome и покупка должны удовлетворять `предыдущий баланс + delta = balance`. На баланс CHECK>=0; все изменения вместе с журналом и idempotency result атомарны. Мебель покупается один раз; повтор с другим ключом отклоняется. Никаких денежных переводов или infinite work endpoints.

Доставка 300–700 ₽, ПК 12000, киоск 25000, квартира 150000, магазин 80000 — только ориентиры из ТЗ для будущего этапа, не доступные покупки. Нужны отдельные ledger accounts, escrow, конкурентные сделки и тесты PostgreSQL до открытия рынка. Балансировка и инфляция ещё не моделировались.
