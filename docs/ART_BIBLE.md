# Арт-направление

Цель финального продукта: подробные рисованные дворы и интерьеры с естественными пропорциями, мягким вечерним светом. Без аниме, chibi, пикселей и emoji-персонажей.

Текущие SVG — **предварительная собственная иллюстрация**, не финальная графика по ТЗ. Повторяющиеся окна, деревья, мебель и портреты требуют художника/генеративного арт-прохода и ручной проверки согласованности. Нет walking/idle/interact-анимаций, атласов и звука.

Палитра: фон #eeece4, текст #384238, шалфей #647760, трава #a6b48f, тёплый свет #f4da9d, терракота #b88760. Не использовать чистый чёрный для теней. Уличная перспектива: горизонтальные оси около ±25°, вертикали прямые. Интерьер — разрез с лёгкой глубиной пола. UI: Georgia для заголовков, Arial/system для действий и русского текста, touch-цели от 44 px.

Экспорт будущего арта: район 2200×1380 и облегчённая 1100×690 WebP; отдельные слои ground/buildings/plants/light/hit zones. Интерьер 2000×1260: стены/пол/мебель/персонажи/свет. Каждый персонаж: world sprite и портрет из одного model sheet. Прозрачные объекты PNG/WebP alpha; атласы после профилирования. Для каждого ресурса — путь, автор/генератор, лицензия, дата, статус в assets-manifest.json. Не использовать чужие игровые спрайты без лицензии.

Замена арта: функции district()/apartment() в art.js — изолированные renderer boundaries. После замены на bitmap привести координаты hotspot к тому же viewBox и проверить все мобильные размеры. Декоративные картинки не меняют серверные инварианты.
