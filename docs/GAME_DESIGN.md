# Ну живи · Последний подъезд

Уютный современный район: знакомство, обустройство, маленькая тайна. Без хоррора, платежей, ставок и наказания за пропуски.

Петля текущей версии: получить квартиру → познакомиться → услышать про №0 → помочь Мише → получить сюжетный ключ (флаг диалога) → обустроить квартиру. Сцена с письмом ещё не написана; журнал прямо говорит, что это конец доступной главы.

Тамара — доброжелательная соседка с хорошей памятью. Миша — сантехник, готовый помочь. Разговоры открываются по порядку, их результат сохраняется, повтор не дублирует прогресс. Отношения пока бинарные сюжетные флаги, не полноценная числовая система.

Игрок получает квартиру и 5000 ₽. Дом вмещает 36 аккаунтов. Нет публичного присутствия других игроков. Закрытые квартиры на сетке подъезда недоступны, не имитируют реальных соседей.
