# Следующие этапы

## Сейчас: проверенный прототип этапов 0–1

Есть серверная авторизация, durable state, 36 квартир на дом, адаптивные SVG-сцены, 2 NPC, история с тремя сохраняемыми шагами, покупка и расстановка одной мебели. CI и конфигурация хостинга подготовлены. До формальной приёмки этапов 0–1 по ТЗ недостаёт целевого стека, PostgreSQL/миграций, TypeScript/lint, качественного финального арта и анимаций.

## Следующая конкретная задача

`npm test && node scripts/browser-test.mjs` — повторить проверки, затем перенести persistence в PostgreSQL с миграциями и сохранить контракт API. После этого TypeScript strict + Zod/Fastify/React; клиентский renderer можно заменить отдельно. Не добавлять ложный multiplayer поверх локального состояния.

## Этап 2

Socket.IO: session authorization, house/location rooms, версия состояния, reconnect, rate limits, deduplication. ApartmentPermission: владелец/гость, проверка доступа на вход и каждое действие. Два настоящих браузерных аккаунта, двусторонний чат, block/report, журнал модерации и интеграционные socket-тесты.

## Этапы 3–5

Работы с проверяемой активностью, inventory, ledger accounts, escrow marketplace и бизнес. Затем законченная история №0, событийный worker, день/погода/звук. Перед публичной бетой: финальный арт, mobile profiling, реальные устройства, нагрузка 20/50/100, security audit, автоматические backup/restore и мониторинг. Эти системы не реализованы.

## Реализовано в 0.3

Заменён SVG-арт на 6 реалистичных ресурсов, завершена трёхглавая история №0 (20 узлов/18 на маршрут), добавлены Семён, находки, две развилки и три подработки с общей механикой проверки последовательности. Ограничения выше для окончания истории/отсутствия работ теперь устарели: отсутствуют именно расширенные мини-игры, рынок/бизнес и социальный realtime. Следующий этап — содержательные разные механики работ, анимации, больше мебели и авторизованный multiplayer с тестами двух клиентов.
